╔════════════════════════════════════════════════════════════════╗
║                    🔧 TROUBLESHOOTING                          ║
╚════════════════════════════════════════════════════════════════╝

❌ "TELEGRAM_BOT_TOKEN not set"
   → Check .env file has correct token (no extra quotes)

❌ "Not authorized"  
   → Your User ID doesn't match TELEGRAM_ADMIN_IDS
   → Send /start to bot to see your ID

❌ Bot doesn't respond
   → Check if running: ps aux | grep telegram-bot
   → Restart: node telegram-bot.js

❌ File not found
   → Use /find first to get exact path
   → Make sure path starts with /Users/
